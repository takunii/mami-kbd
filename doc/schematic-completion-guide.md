# mami42 回路図完成ガイド

## 現在の状態
- **回路図ファイル**: `cad/mami.kicad_sch`
- **マイコン**: ProMicro シンボルが配置済み（U1）
- **キーマトリクス**: 42個のスイッチ（SW1-SW42）とダイオード（D1-D42）が配置済み
- **nice!nanoライブラリ**: 登録済みだが未使用

## 作業手順

### ステップ1: ProMicroからnice!nanoへの変更

#### 1-1. ProMicroシンボルの削除
1. KiCadでmami.kicad_schを開く
2. U1（ProMicro）を選択して削除

#### 1-2. nice!nanoシンボルの配置
1. 「シンボルを配置」ツールを選択（ショートカット: `A`）
2. シンボルライブラリから `mylib:nice_nano` を検索
3. 同じ位置（X:50.8mm, Y:167.64mm）付近に配置
4. リファレンス: `U1`

### ステップ2: ピンアサイン接続

nice!nanoのピン配置に従って、以下のようにラベルを配置して接続します。

**重要**: 物理的には4行ですが、左右分割レイアウトのため、回路図上では8行に分けて配線します。
- 左側の物理4行 → row0～row3
- 右側の物理4行 → row4～row7

#### 2-1. 列（Column）ピンの接続 - 出力

左側ピン:
- **Pin 1** (TX0/P0.06) → ラベル `col0` 
- **Pin 2** (RX1/P0.08) → ラベル `col1`
- **Pin 5** (P0.17) → ラベル `col2`
- **Pin 6** (P0.20) → ラベル `col3`
- **Pin 7** (P0.22) → ラベル `col4`
- **Pin 8** (P0.24) → ラベル `col5`

#### 2-2. 行（Row）ピンの接続 - 入力

左側ピン（続き）:
- **Pin 9** (P1.00) → ラベル `row0` (左側1行目)
- **Pin 10** (P0.11) → ラベル `row1` (左側2行目)
- **Pin 11** (P1.04) → ラベル `row2` (左側3行目)
- **Pin 12** (P1.06) → ラベル `row3` (左側4行目)

右側ピン:
- **Pin 13** (P0.09/NFC1) → ラベル `row4` (右側1行目)
- **Pin 14** (P0.10/NFC2) → ラベル `row5` (右側2行目)
- **Pin 15** (P1.11) → ラベル `row6` (右側3行目)
- **Pin 16** (P1.13) → ラベル `row7` (右側4行目)

#### 2-3. 電源ピンの接続

- **Pin 21** (VCC) → VCC電源シンボル
- **Pin 3, 4, 23, 30** (GND) → GND電源シンボル（すべて接続）
- **Pin 22** (RST) → リセットボタン回路（オプション）

### ステップ3: マトリクスとの接続確認

#### 3-1. 既存のラベルを確認
キーマトリクスには既に以下のラベルがあるはずです：
- 列: col0～col5（6列）
- 行: row0～row7（8行 - 左側4行 + 右側4行）

#### 3-2. ラベルの一致確認
nice!nanoから出るラベルとマトリクスのラベルが一致していることを確認

### ステップ4: バッテリー回路の追加（オプション）

無線動作を行う場合、以下の回路を追加します：

#### 4-1. バッテリーコネクタの配置
1. `Connector:Conn_01x02_Pin` を配置（J1）
2. フットプリント: `Connector_JST:JST_PH_B2B-PH-K_1x02_P2.00mm_Vertical`

#### 4-2. バッテリー回路の接続
```
[Battery+] --- [Power Switch] --- J1-Pin1 --- nice!nano Pin24/34 (BATIN)
[Battery-] ------------------- J1-Pin2 --- GND
```

パワースイッチ（オプション）:
- `Switch:SW_SPST` を使用
- バッテリー＋とBATIN間に配置

### ステップ5: リセットボタン回路の追加（オプション）

#### 5-1. タクトスイッチの配置
1. `Switch:SW_Push` を配置（SW_RST）
2. フットプリント: `Button_Switch_SMD:SW_SPST_B3U-1000P`

#### 5-2. 接続
```
nice!nano RST (Pin22) --- [SW_RST] --- GND
```

プルアップ抵抗（10kΩ）をRSTとVCC間に追加することを推奨

### ステップ6: 電源回路の整理

#### 6-1. デカップリングキャパシタの追加
1. VCCとGND間に0.1μFコンデンサを3～4個配置
2. フットプリント: `Capacitor_SMD:C_0603_1608Metric`
3. nice!nano近くに配置

#### 6-2. バイパスキャパシタ
必要に応じて10μF電解コンデンサを追加

### ステップ7: ERC（Electric Rule Check）の実行

1. メニュー → Inspect → Electrical Rules Checker
2. エラーがないことを確認
3. 警告を確認し、必要に応じて修正

主な確認ポイント:
- すべてのピンが接続されているか
- 電源ピンが正しく接続されているか
- ラベルの名前が一致しているか

### ステップ8: フットプリントの割り当て

1. メニュー → Tools → Assign Footprints
2. 各シンボルに適切なフットプリントを割り当て

主要なフットプリント:
- nice!nano: カスタムフットプリント（作成必要）または `MCU_Module:Arduino_Nano`を改造
- ダイオード: `Diode_SMD:D_SOD-123`（既に設定済み）
- キースイッチ: `kbd:keyswitch_cherrymx_hotswap_1u`（既に設定済み）
- コンデンサ: `Capacitor_SMD:C_0603_1608Metric`

### ステップ9: ネットリストの生成

1. メニュー → File → Export → Netlist
2. ファイル名: `mami.net`
3. PCB設計へ移行する前に保存

## トラブルシューティング

### Q: nice!nanoシンボルが見つからない
A: `cad/symbols/nice-nano.lib`がレガシー形式です。KiCad 6以降では新しいシンボルライブラリ形式への変換が必要な場合があります。または、手動でnice!nanoと同等のシンボルを作成してください。

### Q: ピン番号が一致しない
A: nice!nano v2のピン配置を確認してください。データシートと照合することを推奨します。

### Q: ERCでエラーが出る
A: 
- "Unconnected"エラー: すべてのピンが接続されているか確認
- "Pin not driven"エラー: 電源ピンがVCC/GNDに接続されているか確認
- "Conflicting"エラー: 同じネット名に複数の異なる電圧が接続されていないか確認
