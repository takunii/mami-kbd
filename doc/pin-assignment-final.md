# mami42 最終ピンアサイン（裏面実装最適化）

## 🎯 最適化の考え方

### PCB裏面実装での配置
```
        PCB表面から見た配置
        
マトリクス左側          nice!nano(裏面)          マトリクス右側
  (左に配置)            (中央に配置)              (右に配置)
                    
                    回路図右側ピン
                    → 実装後は左側
                    → マトリクス左側に近い！
                    
                    回路図左側ピン  
                    → 実装後は右側
                    → マトリクス右側に近い！
```

### ✅ 最適化の原則
1. **ROW左側（4本）**: 回路図の**右側ピン**を使用 → 実装後は左側
2. **ROW右側（4本）**: 回路図の**左側ピン**を使用 → 実装後は右側
3. **COL（6本）**: 残りのピンを上側から順に使用
4. **横断配線を最小化**: ROWが左右に分かれているため横断不要

## 🔧 確定ピンアサイン

### 列（COL）ピン - 6本
```
col0: Pin 1  (P0.06/TX0)  - 回路図左側最上部 → 実装後は右側
col1: Pin 2  (P0.08/RX1)  - 回路図左側上部   → 実装後は右側
col2: Pin 5  (P0.17)      - 回路図左側上部   → 実装後は右側
col3: Pin 6  (P0.20)      - 回路図左側中央   → 実装後は右側
col4: Pin 7  (P0.22)      - 回路図左側中央   → 実装後は右側
col5: Pin 8  (P0.24)      - 回路図左側中央   → 実装後は右側
```
**配置**: COLが中央（実装後右側）に集約され、左右のマトリクスに配線しやすい

### 行（ROW）ピン - 左側4本
```
row0: Pin 13 (P0.09/NFC1) - 回路図右側最上部 → 実装後は左側 ⭐
row1: Pin 14 (P0.10/NFC2) - 回路図右側上部   → 実装後は左側 ⭐
row2: Pin 15 (P1.11)      - 回路図右側上部   → 実装後は左側 ⭐
row3: Pin 16 (P1.13)      - 回路図右側上部   → 実装後は左側 ⭐
```
**配置**: 実装後は左側に来るため、マトリクス左側への配線が短い！

### 行（ROW）ピン - 右側4本
```
row4: Pin 9  (P1.00)      - 回路図左側下部   → 実装後は右側 ⭐
row5: Pin 10 (P0.11)      - 回路図左側下部   → 実装後は右側 ⭐
row6: Pin 11 (P1.04)      - 回路図左側下部   → 実装後は右側 ⭐
row7: Pin 12 (P1.06)      - 回路図左側最下部 → 実装後は右側 ⭐
```
**配置**: 実装後は右側に来るため、マトリクス右側への配線が短い！

### 電源・その他
```
VCC:   Pin 21 (回路図右側下部)
```

## 📐 配線イメージ（実装後・表面から見た場合）

```
マトリクス左側                nice!nano(裏面)               マトリクス右側
  (物理4行)                   (表面から見て)                  (物理4行)
                        
  row0 ─────→ Pin 13 (左側上部) ←─ 短い！
  row1 ─────→ Pin 14                         
  row2 ─────→ Pin 15                          Pin 9 (右側下部) ←──── row4
  row3 ─────→ Pin 16                          Pin 10             ←──── row5
                                              Pin 11             ←──── row6
                                              Pin 12 (右側下部)  ←──── row7
                                                     ↑
                                                   短い！
                                                   
  ← COL信号は中央(右側)から左右に分配 →
     Pin 1-8 (右側上～中央)
```

## ✅ この配線の利点

### 1. 横断配線がゼロ
- **ROW左（13-16）** → 実装後左側 → マトリクス左側に直接配線
- **ROW右（9-12）** → 実装後右側 → マトリクス右側に直接配線
- 横断する必要なし！

### 2. 配線が短い
- ROW信号が各マトリクス側に近い位置から出る
- 配線長が最短

### 3. 信号の分離
- ROW左は上部（Pin 13-16）
- ROW右は下部（Pin 9-12）
- 上下で分離されているため交差なし

### 4. COL信号の配線
- COL（Pin 1-8）は実装後右側中央に位置
- 左右のマトリクスに均等にアクセス可能

## 💻 ZMK ファームウェア設定

```dts
/ {
    chosen {
        zmk,kscan = &kscan0;
    };

    kscan0: kscan {
        compatible = "zmk,kscan-gpio-matrix";
        label = "KSCAN";
        diode-direction = "col2row";
        
        row-gpios
            = <&gpio0 9 (GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN)>   // P0.09 - row0 (左側)
            , <&gpio0 10 (GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN)>  // P0.10 - row1 (左側)
            , <&gpio1 11 (GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN)>  // P1.11 - row2 (左側)
            , <&gpio1 13 (GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN)>  // P1.13 - row3 (左側)

            , <&gpio0 11 (GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN)>  // P0.11 - row5 (右側)
            , <&gpio1 4 (GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN)>   // P1.04 - row6 (右側)
```

## ✅ まとめ

### この最終ピンアサインを使用する理由：
1. **横断配線ゼロ**: ROWが左右に分かれているため
2. **配線が最短**: 各ROWが対応するマトリクス側に直接接続
3. **信号の分離**: 上下で分離され交差なし
4. **PCB設計が簡単**: ルーティングが直感的
