### シンボルサイズ
- 図面上のサイズ: 1000 × 1600 単位（回路図表示用）
- これは回路図上での視認性のためのサイズで、実際のPCBサイズとは異なります

### 実際のnice!nano v2サイズ
- 長さ: 33.02mm
- 幅: 18.0mm
- ピンピッチ: 2.54mm（100mil）
- Pro Micro互換のフットプリント

## 使用可能性

### ✅ このシンボルは使用可能です

**理由:**
1. 全34ピンのピン配置が正確
2. ピン名称が正しい（P0.06, P1.00など）
3. 電源ピン（VCC, GND, BATIN）が適切に配置
4. 通信ピン（TX0, RX1）が正しい位置

## 次のステップ: KiCadでの置き換え手順

### 1. ProMicroシンボルの削除
```
1. mami.kicad_sch を KiCad で開く
2. U1 (ProMicro) を選択
3. Delete キーで削除
```

### 2. nice!nanoシンボルの配置
```
1. ショートカット 'A' キーを押す
2. "nice_nano" を検索（ライブラリ: mylib）
3. 同じ位置に配置（X:50.8mm, Y:167.64mm付近）
4. リファレンスを "U1" に設定
```

### 3. ピン接続
回路図ガイド（`doc/schematic-completion-guide.md`）に従ってピンを接続：
- 6列ピン（col0-5）: Pin 1,2,5,6,7,8
- 8行ピン（row0-7）: Pin 9,10,11,12,13,14,15,16
- 電源: VCC(21), GND(3,4,23,30)
- その他: RST(22), BATIN(24,34)

## フットプリントについて

### 必要なフットプリント
nice!nano用のフットプリントが必要です。オプションは：

#### オプション1: Pro Micro互換フットプリント
- `kbd:ProMicro` フットプリントがあればそのまま使用可能
- nice!nanoはPro Micro互換なので物理的に適合

#### オプション2: カスタムフットプリント作成
- nice!nano専用フットプリントを作成
- スルーホールまたはMill-Maxソケット用に最適化

#### オプション3: 既存ライブラリから
- KiCad標準ライブラリの `MCU_Module:Arduino_Nano` を改造
- nice!nanoのピン配置に合わせて調整
