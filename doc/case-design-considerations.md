# mami42 ケース設計の考察

このドキュメントでは、Aliceレイアウトキーボードのケース設計における選択肢と課題をまとめます。

---

## 発見事項

**Alice keyboardはsilicon gasket構造に向かない**

### Silicon Gasket構造とは

Silicon gasket mount（ガスケットマウント）：
- PCBをケースに直接固定せず、シリコンガスケット（柔らかいクッション）で支える
- 打鍵感が柔らかく、静音性が高い
- 高級キーボードで人気の構造

```
トップケース
    ↓
[シリコンガスケット]
    ↓
    PCB
    ↓
[シリコンガスケット]
    ↓
ボトムケース
```

---

## Aliceレイアウトでの課題

### 課題1: 複雑な形状

#### 問題点
- Aliceレイアウトは**左右が角度を持って配置**
- 中央に大きな空間がある
- 通常の長方形キーボードと異なる複雑な外形

#### ガスケット構造との不整合
- ガスケットは**均等な圧力**が必要
- 角度のある形状では圧力が均等にかからない
- 中央スペースでガスケットが支えられない
- PCBがたわみやすい

### 課題2: CNCケース1枚の場合

#### 構造
```
CNCケース1枚構造:
┌──────────────────┐
│                  │ ← トップケース（CNC加工）
│      [隙間]      │
│                  │
│     ↓ PCB挿入   │
│                  │
└──────────────────┘
```

#### 問題点
1. **組み立ての難しさ**
   - PCBを隙間から横に差し込む必要がある
   - キースイッチがすでに装着されていると入らない
   - ホットスワップの場合、スイッチを全部外す必要がある

2. **メンテナンス性**
   - 分解・組み立てが面倒
   - スイッチ交換のたびに全分解が必要
   - USB接続の抜き差しが困難

3. **強度の問題**
   - 隙間部分が弱点になる
   - 横からの力に弱い
   - PCBの固定が不安定

---

## Aliceレイアウトに適したケース構造

### オプション1: トップ＋ボトム分離式（推奨）⭐

最も一般的で実用的な構造

#### 構造
```
┌──────────────────┐
│  トップケース    │ ← CNC/3Dプリント
└──────────────────┘
        ↓
   [スペーサー]
        ↓
      PCB
        ↓
   [スペーサー]
        ↓
┌──────────────────┐
│  ボトムケース    │
└──────────────────┘
```

#### メリット
- ✅ 組み立てが簡単
- ✅ メンテナンス性が高い
- ✅ PCBの交換が容易
- ✅ マイコン・バッテリーへのアクセス良好
- ✅ 強度が高い

#### デメリット
- ケース部品が2つ必要（コスト増）
- ネジ穴が見える（美観）

#### 実装方法
1. トップケースにキースイッチの穴を開ける
2. PCBにスタンドオフ（スペーサー）を取り付け
3. ボトムケースをネジで固定

---

### オプション2: サンドイッチマウント

シンプルで低コストな構造

#### 構造
```
トッププレート
    ↓
  PCB
    ↓
ボトムプレート
    ↓
長ネジで固定
```

#### メリット
- ✅ 低コスト（アクリル/FR4板で製作可能）
- ✅ 軽量
- ✅ 組み立てが簡単
- ✅ カスタマイズ性が高い

#### デメリット
- PCBが露出（見た目）
- 防塵性が低い
- 高級感は劣る

---

### オプション3: トレイマウント

PCBをケースに直接ネジ止め

#### 構造
```
┌──────────────────┐
│                  │
│  PCB（ネジ固定） │
│                  │
└──────────────────┘
```

#### メリット
- ✅ シンプルな構造
- ✅ コスト削減
- ✅ 一体感のある見た目

#### デメリット
- 打鍵感が硬い
- 振動がケースに伝わる
- 静音性が低い

---

### オプション4: インテグレートプレート

トッププレートとPCBが一体化

#### 構造
```
キースイッチ → トッププレート → PCB（一体）
                      ↓
                 ボトムケース
```

#### メリット
- PCBが薄い
- ミニマルな設計

#### デメリット
- PCBの製造コストが高い
- 修理が困難

---

## mami42の推奨ケース構造

### 推奨: トップ＋ボトム分離式

#### 理由
1. **Aliceレイアウトに最適**
   - 複雑な形状に対応しやすい
   - 中央スペースの処理が容易

2. **無線キーボードに適している**
   - バッテリー交換が簡単
   - マイコンへのアクセス良好
   - USB充電ポートを配置しやすい

3. **メンテナンス性**
   - スイッチ交換が容易
   - トラブル時の修理が簡単

4. **実装のしやすさ**
   - CNC、3Dプリント、両方で製作可能
   - 設計が比較的簡単

---

## 具体的な実装案

### 構成例

#### トップケース
- 材質: アルミニウム（CNC加工）または樹脂（3Dプリント）
- 厚み: 5～8mm
- キースイッチ穴: 14mm × 14mm（Cherry MX）
- USB穴: 背面または側面に配置

#### PCB
- 厚み: 1.6mm
- スタンドオフ: M2ネジ、高さ8～12mm
- 取り付け穴: 4～6箇所（バランス良く配置）

#### ボトムケース
- 材質: トップケースと同じ
- 厚み: 3～5mm
- 滑り止め用ゴム足取り付け穴
- マイコン・バッテリーアクセス用の窓（オプション）

#### スペーサー構成
```
トップケース
    ↓
PCB（表面: キースイッチ、裏面: マイコン）
    ↓ 8~12mm
ボトムケース
    ↓
ゴム足
```

## Silicon Gasketを諦める理由まとめ

1. **形状の不整合**
   - Aliceレイアウトの角度と複雑な形状
   - ガスケットの均等な圧力確保が困難

2. **中央スペースの問題**
   - 中央に大きな空間があるため、PCBの支持が不均一
   - たわみやすい

3. **コストと複雑さ**
   - ガスケット用の溝加工が必要
   - 設計・製造の難易度が高い
   - コストが大幅に増加

4. **代替案の方が実用的**
   - トップ＋ボトム分離式で十分な品質
   - Cherry Profileの打鍵感で満足できる
   - メンテナンス性が高い

---

## CNCケース1枚構造を避ける理由

### 問題点の詳細

#### 1. 組み立て手順の複雑さ
```
手順:
1. PCBにすべての部品をはんだ付け
2. キースイッチは装着しない（入らないため）
3. PCBを横から隙間に挿入
4. PCBを固定
5. キースイッチを1個ずつ装着

問題:
- ホットスワップなのにスイッチを外す必要がある
- 隙間が狭いと挿入が困難
- PCBが傷つきやすい
```

#### 2. USB接続の問題
- ケース内部にマイコンがあるため、USBポートが見えない
- ケースに穴を開ける必要があるが、位置合わせが難しい
- USB-Cコネクタの抜き差しでPCBに負荷がかかる

#### 3. バッテリー交換
- 無線キーボードの場合、バッテリー交換が頻繁
- 1枚構造では毎回分解が必要
- 実用的ではない

---

## 結論と推奨事項

### mami42のケース設計推奨

**トップ＋ボトム分離式（スタンドオフ固定）**

#### 利点
- ✅ 組み立てが簡単
- ✅ メンテナンス性が高い
- ✅ Aliceレイアウトに最適
- ✅ 無線キーボードに適している
- ✅ コストと品質のバランスが良い

#### 製作方法の選択肢
1. **CNCアルミニウム**: 高級感、重厚感、耐久性
2. **3Dプリント樹脂**: 低コスト、デザイン自由度高、軽量
3. **アクリル板**: 超低コスト、透明感、DIY向け

### Silicon Gasketは将来の検討課題
- 技術的には可能だが、設計難易度とコストが高い
- まずはシンプルな構造で完成させることを優先
- 将来のバージョンで検討可能

## 参考: 他のAliceキーボードのケース

- **Keychron Q8 Alice**: トップ＋ボトム分離式
- **Switch Couture Alice**: サンドイッチマウント（アクリル）
- **YMDK Alice**: トレイマウント
- **TGR Alice**: 高級CNCアルミケース（分離式）

ほとんどのAliceキーボードが**分離式**を採用しているのは、実用性と品質のバランスが最も良いためです。

## チェックリスト

### ケース設計時の確認事項

- [ ] トップ＋ボトム分離式を採用
- [ ] PCB取り付け穴の位置を決定（4～6箇所）
- [ ] スタンドオフの高さを決定（8～12mm）
- [ ] USB穴の位置とサイズを決定
- [ ] ケース側面のスイッチ穴を設計（ケース側装着の場合）
- [ ] ゴム足の位置を決定
- [ ] ケース材質を選択（CNC/3Dプリント/アクリル）
- [ ] ネジ穴の位置を設計（M2推奨）

---

## まとめ

Silicon gasket構造は魅力的ですが、Aliceレイアウトには不向きです。**トップ＋ボトム分離式**が最も実用的で、組み立てやメンテナンスが容易です。CNCケース1枚構造も避け、シンプルで確実な設計を優先することをお勧めします。
