# PCB DRC（デザインルールチェック）トラブルシューティング

このドキュメントは、KiCad PCBエディタで発生するDRCエラーの解決方法をまとめます。

---

## 現在のエラー: D57 基板端クリアランス違反

### エラー内容
```
セグメント of D57 Edge.Cuts上
基板端クリアランス違反
```

### 原因
D57（ダイオード）のフットプリントまたは配線が基板端（Edge.Cuts）に近すぎて、デザインルールで定義されたクリアランス（通常0.2mm～0.5mm）を満たしていません。

---

## 解決方法

### 方法1: D57の位置を移動する（推奨）

1. **KiCad PCBエディタを開く**
   - `cad/mami.kicad_pcb` を開く

2. **D57を見つける**
   - ツールバー → 検索アイコン（虫眼鏡）をクリック
   - 「D57」と入力して検索
   - または、画面上でD57を探す

3. **D57を基板内側に移動**
   - D57を選択（クリック）
   - `M`キーを押して移動モード
   - 基板端から少なくとも**0.5mm以上**離れた位置に移動
   - クリックして配置確定

4. **配線を修正**
   - 移動により切断された配線を再接続
   - または、`Delete`で古い配線を削除して再配線

5. **DRCを再実行**
   - メニュー → Inspect → Design Rules Checker
   - `Run DRC`をクリック
   - エラーが消えたことを確認

### 方法2: 基板端を拡張する

D57を移動できない場合は、基板サイズを拡張します。

1. **Edge.Cutsレイヤーを選択**
   - 右側のレイヤーパネルで `Edge.Cuts` をクリック

2. **基板外形線を編集**
   - 外形線を選択
   - `E`キーで編集モード
   - 線を外側に移動して基板を拡張

3. **DRCを再実行**

### 方法3: デザインルールを調整（非推奨）

**注意**: 製造業者の最小仕様を下回らないように注意してください。

1. **デザインルール設定を開く**
   - メニュー → File → Board Setup
   - `Design Rules` → `Constraints` を選択

2. **基板端クリアランスを確認/変更**
   - `Copper Clearance` セクション
   - `Board Edge Clearance` の値を確認
   - 必要に応じて小さくする（例: 0.3mm → 0.2mm）
   - ただし、**製造業者の最小仕様（通常0.2mm以上）を確認すること**

3. **DRCを再実行**

## 基板端クリアランスのベストプラクティス

### 推奨クリアランス値

| 対象 | 最小値 | 推奨値 | 備考 |
|------|--------|--------|------|
| SMD部品 | 0.3mm | 0.5mm以上 | 特にダイオード、抵抗 |
| パッド | 0.2mm | 0.4mm以上 | 製造業者の仕様による |
| 配線（トレース） | 0.2mm | 0.3mm以上 | 幅に応じて調整 |
| スルーホール | 0.3mm | 0.5mm以上 | ドリル径＋余裕 |

### なぜクリアランスが必要か

1. **製造精度**: PCB製造時の位置ずれやルーターの誤差に対応
2. **機械的強度**: 基板端近くの部品は剥がれやすい
3. **Vカット/ルーティング**: パネル分離時の破損防止
4. **電気的安全性**: 基板端からの漏電防止

## よくあるDRCエラーと解決方法

### 1. 基板端クリアランス違反（Edge Clearance）
- **原因**: 部品や配線が基板端に近すぎる
- **解決**: 部品を移動、基板サイズを拡張

### 2. トレース幅違反（Track Width）
- **原因**: 配線幅が細すぎる/太すぎる
- **解決**: 配線を引き直す、デザインルールを見直す

### 3. クリアランス違反（Clearance）
- **原因**: 配線/パッド同士が近すぎる
- **解決**: 配線を移動、部品を再配置

### 4. ビア配置違反（Via）
- **原因**: ビアがパッドに近すぎる
- **解決**: ビアを移動

### 5. DRC設定の確認
- メニュー → File → Board Setup → Design Rules
- `Constraints`タブで各種クリアランス値を確認

## D57の特定方法

### KiCad PCBエディタでの検索
```
1. メニュー → Edit → Find (Ctrl+F)
2. "D57" と入力
3. "Find Next" をクリック
4. D57にズーム・ハイライト表示される
```

### D57の情報確認
- D57を選択 → `E`キー（プロパティ表示）
- または、右クリック → Properties
- 位置（X, Y座標）、フットプリント、レイヤー情報を確認

## チェックリスト

### DRC実行前の確認
- [ ] すべての部品が配置されている
- [ ] すべての配線が完了している
- [ ] 基板外形（Edge.Cuts）が閉じている
- [ ] グランドプレーンが適切に配置されている

### DRCエラー修正後
- [ ] DRCを再実行してエラー0を確認
- [ ] 目視で部品配置を確認
- [ ] 3Dビューで干渉確認（View → 3D Viewer）
- [ ] ガーバーファイルでプレビュー確認

## 参考: 標準的なPCB製造仕様

### JLCPCB（低コスト製造業者）
- 最小トレース幅: 0.127mm (5mil)
- 最小クリアランス: 0.127mm (5mil)
- 最小穴径: 0.3mm
- **基板端クリアランス: 0.2mm以上推奨**

### Elecrow
- 最小トレース幅: 0.152mm (6mil)
- 最小クリアランス: 0.152mm (6mil)
- **基板端クリアランス: 0.3mm以上推奨**

**重要**: 実際の製造業者の仕様を必ず確認してください。

---

## まとめ

1. **D57を基板内側に移動**（最も簡単な解決策）
2. 基板端から**0.5mm以上**のクリアランスを確保
3. DRCを再実行してエラー0を確認
4. 製造業者の仕様を常に確認

DRCエラーは製造不良や不具合の原因となるため、必ず修正してください。
