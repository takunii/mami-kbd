# PCB DRC（デザインルールチェック）トラブルシューティング

このドキュメントは、KiCad PCBエディタで発生するDRCエラーの解決方法をまとめます。

---

## 現在のエラー: D57 基板端クリアランス違反

### エラー内容
```
セグメント of D57 Edge.Cuts上
基板端クリアランス違反
```

### 原因
**D57は実際にはLED（SK6812MINI-E）** - 回路図のラベリングがダイオードの"D"になっていますが、実体はRGB LEDです。

このエラーは、D57（SK6812MINI-E）のフットプリントまたは配線が基板端（Edge.Cuts）に近すぎて、デザインルールで定義されたクリアランス（通常0.2mm～0.5mm）を満たしていないために発生しています。

### なぜSMD部品でエラーが出やすいか

SK6812MINI-EのようなSMD（表面実装）部品は、特に基板端クリアランスに注意が必要です：

1. **フットプリントが小さい**
   - SK6812MINI-Eは3.2mm × 2.8mmと小型
   - わずかな配置ミスでもクリアランス違反になりやすい

2. **パッドが端部にある**
   - 4つのパッドが部品の四隅にあるため、基板端に近いとパッドが製造時に破損しやすい

3. **製造時のリスク**
   - 基板端近くのSMD部品は、パネル分離（Vカット/ルーティング）時に剥がれやすい
   - ルーターのビットやVカッターの振動で部品が破損する可能性がある

4. **はんだ付けの難しさ**
   - 基板端近くは熱が逃げやすく、リフロー時の温度管理が難しい
   - 手はんだの場合、こてを当てにくい

**結論**: SMD部品（特にLED）は基板端から**0.5mm以上**離すことを強く推奨します。

## 解決方法

### 方法1: D57（LED）の位置を移動する（推奨）

1. **KiCad PCBエディタを開く**
   - `cad/mami.kicad_pcb` を開く

2. **D57を見つける**
   - ツールバー → 検索アイコン（虫眼鏡）をクリック
   - 「D57」と入力して検索
   - または、画面上でD57（SK6812MINI-E LED）を探す

3. **D57を基板内側に移動**
   - D57を選択（クリック）
   - `M`キーを押して移動モード
   - 基板端から少なくとも**0.5mm以上**離れた位置に移動
   - **LED用推奨**: できれば**0.8～1.0mm**のクリアランスを確保
   - クリックして配置確定

4. **配線を修正**
   - 移動により切断された配線を再接続
   - または、`Delete`で古い配線を削除して再配線
   - LEDの4本の信号線（VDD, VSS, DIN, DOUT）をすべて再接続

5. **DRCを再実行**
   - メニュー → Inspect → Design Rules Checker
   - `Run DRC`をクリック
   - エラーが消えたことを確認

**LED配置のヒント**:
- 他のLEDとの間隔も確認（信号線の配線スペース確保）
- 光が均等に広がる位置に配置
- キースイッチと干渉しないか確認

### 方法2: 基板端を拡張する

D57を移動できない場合は、基板サイズを拡張します。

1. **Edge.Cutsレイヤーを選択**
   - 右側のレイヤーパネルで `Edge.Cuts` をクリック

2. **基板外形線を編集**
   - 外形線を選択
   - `E`キーで編集モード
   - 線を外側に移動して基板を拡張

3. **DRCを再実行**

### 方法3: デザインルールを調整（非推奨）

**注意**: 製造業者の最小仕様を下回らないように注意してください。

1. **デザインルール設定を開く**
   - メニュー → File → Board Setup
   - `Design Rules` → `Constraints` を選択

2. **基板端クリアランスを確認/変更**
   - `Copper Clearance` セクション
   - `Board Edge Clearance` の値を確認
   - 必要に応じて小さくする（例: 0.3mm → 0.2mm）
   - ただし、**製造業者の最小仕様（通常0.2mm以上）を確認すること**

3. **DRCを再実行**

## 基板端クリアランスのベストプラクティス

### 推奨クリアランス値

| 対象 | 最小値 | 推奨値 | 備考 |
|------|--------|--------|------|
| **SMD LED（SK6812MINI-E等）** | **0.5mm** | **0.8～1.0mm** | **特に重要：製造時の破損防止** |
| SMD部品（一般） | 0.3mm | 0.5mm以上 | ダイオード、抵抗、コンデンサ |
| パッド | 0.2mm | 0.4mm以上 | 製造業者の仕様による |
| 配線（トレース） | 0.2mm | 0.3mm以上 | 幅に応じて調整 |
| スルーホール | 0.3mm | 0.5mm以上 | ドリル径＋余裕 |

### なぜクリアランスが必要か

1. **製造精度**: PCB製造時の位置ずれやルーターの誤差に対応
2. **機械的強度**: 基板端近くの部品は剥がれやすい
3. **Vカット/ルーティング**: パネル分離時の破損防止
4. **電気的安全性**: 基板端からの漏電防止

## よくあるDRCエラーと解決方法

### 1. 基板端クリアランス違反（Edge Clearance）
- **原因**: 部品や配線が基板端に近すぎる
- **解決**: 部品を移動、基板サイズを拡張

### 2. トレース幅違反（Track Width）
- **原因**: 配線幅が細すぎる/太すぎる
- **解決**: 配線を引き直す、デザインルールを見直す

### 3. クリアランス違反（Clearance）
- **原因**: 配線/パッド同士が近すぎる
- **解決**: 配線を移動、部品を再配置

### 4. ビア配置違反（Via）
- **原因**: ビアがパッドに近すぎる
- **解決**: ビアを移動

### 5. DRC設定の確認
- メニュー → File → Board Setup → Design Rules
- `Constraints`タブで各種クリアランス値を確認

## D57（LED）の特定方法

### KiCad PCBエディタでの検索
```
1. メニュー → Edit → Find (Ctrl+F)
2. "D57" と入力
3. "Find Next" をクリック
4. D57（SK6812MINI-E LED）にズーム・ハイライト表示される
```

### D57の情報確認
- D57を選択 → `E`キー（プロパティ表示）
- または、右クリック → Properties
- 位置（X, Y座標）、フットプリント、レイヤー情報を確認
- フットプリント: `LED_SMD:LED_SK6812MINI-E_3.2x2.8mm_P1.5mm_ReverseMount` 等

### ラベリングの注意
- 回路図では「D57」（ダイオードのD）と表示されていますが、実体はLED（SK6812MINI-E）です
- KiCadでは慣習的にLEDもダイオード扱いで"D"の記号を使用することがあります
- リファレンス記号の変更方法:
  1. 回路図エディタでD57を選択 → `E`キー
  2. Reference: `D57` → `LED57` に変更（推奨）
  3. アノテーション更新（Tools → Annotate Schematic）

## 参考: 標準的なPCB製造仕様

- 最小トレース幅: 0.127mm (5mil)
- 最小クリアランス: 0.127mm (5mil)
- 最小穴径: 0.3mm
- **基板端クリアランス: 0.2mm以上推奨**

- 最小トレース幅: 0.152mm (6mil)
- 最小クリアランス: 0.152mm (6mil)
- **基板端クリアランス: 0.3mm以上推奨**

**重要**: 実際の製造業者の仕様を必ず確認してください。

## まとめ

1. **D57（SK6812MINI-E LED）を基板内側に移動**（最も簡単な解決策）
2. 基板端から**0.8～1.0mm**のクリアランスを確保（LED推奨値）
3. DRCを再実行してエラー0を確認
4. 製造業者の仕様を常に確認

### SMD LED（SK6812MINI-E）特有の注意点
- 小型で精密なため、基板端に配置すると製造時に破損しやすい
- パネル分離（Vカット/ルーティング）時の振動に弱い
- 十分なクリアランスを確保することで歩留まり向上

DRCエラーは製造不良や不具合の原因となるため、必ず修正してください。
