# D46 基板端クリアランス違反の修正ガイド

## 現在の状況（スクリーンショット確認済み）

**D46**（SK6812MINI-E LED）が基板の上端に非常に近く、DRCエラーが発生しています。

### 見えている状況
- D46のフットプリント（4つの赤いパッド）が基板端に接近
- SW7（キースイッチ）の下に配置されている
- 黄色のキースイッチフットプリントと青いキーキャップエリアが見える

---

## 解決方法の選択肢

### オプション1: D46を下方向（基板内側）に移動する ⭐推奨⭐

この方法が最も簡単で効果的です。

#### 手順

1. **D46を選択**
   - D46のLEDフットプリント（中央の小さい四角形）をクリック
   - またはすでに選択されている場合はそのまま

2. **移動モードに入る**
   - キーボードの `M` キーを押す
   - または、右クリック → `Move`

3. **下方向に移動**
   - マウスを**下方向**（基板内側）に動かす
   - 目安: **1.0～1.5mm程度**下に移動
   - グリッドに合わせて配置（通常0.5mmグリッド）

4. **配置確定**
   - クリックして配置を確定

5. **配線を修正**
   - 移動により切断された4本の信号線を再接続:
     - VDD（電源）
     - VSS（GND）
     - DIN（データ入力）
     - DOUT（データ出力）
   - `X`キーで配線ツールを起動
   - または、自動配線機能を使用

6. **DRC確認**
   - メニュー → Inspect → Design Rules Checker
   - `Run DRC`をクリック
   - D46のエラーが消えたことを確認

#### 移動の目安
```
現在: 基板端から約0.2mm（エラー）
     ↓
移動後: 基板端から1.0mm以上（OK）
```

---

### オプション2: キースイッチとLEDの位置関係を調整

SW7（キースイッチ）の位置も調整できる場合：

1. **SW7とD46を一緒に選択**
   - Shiftを押しながらSW7とD46の両方をクリック

2. **グループで移動**
   - `M`キーで移動
   - 基板内側に移動

3. **レイアウト全体を確認**
   - 他のキーとの間隔を確認
   - 必要に応じて周辺のキーも調整

**注意**: この方法はキーボードレイアウト全体に影響するため、慎重に検討してください。

---

### オプション3: 基板を拡張する

D46やSW7を動かせない場合：

1. **Edge.Cutsレイヤーを選択**
   - 右側のレイヤーリストで`Edge.Cuts`をクリック

2. **基板外形線を選択**
   - 基板の上端の線（D46に近い線）をクリック

3. **線を編集**
   - `E`キーで編集モード
   - 線を**上方向**（外側）に1～2mm移動
   - 基板を大きくする

4. **DRC確認**

## 推奨する配置

### LEDとキースイッチの理想的な配置

```
基板端（Edge.Cuts）
━━━━━━━━━━━━━━━━━━━━
     ↑
   1.0mm以上のクリアランス
     ↑
┌────────────┐
│  D46 LED   │  SK6812MINI-E（3.2mm × 2.8mm）
└────────────┘
     ↓
  LEDの配置位置
     ↓
   SW7（キースイッチ）の下または近く
```

### チェックポイント

- [ ] D46が基板端から1.0mm以上離れている
- [ ] SW7（キースイッチ）と干渉していない
- [ ] 配線がすべて接続されている（VDD, VSS, DIN, DOUT）
- [ ] 他のLED（D45, D47等）との信号チェーンが正しい
- [ ] DRCエラーが0件

---

## 具体的な移動量の計算

スクリーンショットから推定される現在の状態：
- 現在のD46の位置: 基板端から約**0.2～0.3mm**
- 必要なクリアランス: **1.0mm**
- **移動量: 下方向に0.7～0.8mm**

### KiCadでの移動

1. D46を選択して`M`キー
2. グリッド設定を確認（View → Grid Settings）
   - 推奨: 0.5mmグリッドまたは0.25mmグリッド
3. グリッド1～2マス分下に移動（0.5mm～1.0mm）
4. 配置確定

## トラブルシューティング

### Q: D46を動かすとSW7の下から外れてしまう
A: LEDの光がキーの下に来るように、SW7も一緒に移動するか、LEDを別の位置に移動してください。

### Q: 配線が複雑で再配線が難しい
A: 
1. `Delete`キーで古い配線をすべて削除
2. 配線ツール（`X`キー）で一本ずつ再配線
3. または、自動配線ツールを使用

### Q: 移動後、他のLEDの信号チェーンが壊れた
A: LED信号チェーンは以下の順序で接続されています：
```
LED_前 → DOUT → DIN → D46 → DOUT → DIN → LED_次
```
信号線（DIN/DOUT）の接続を確認してください。

### Q: グリッドにスナップして細かい調整ができない
A: 
1. グリッド設定を細かくする（0.25mmや0.1mm）
2. または、グリッドスナップを一時的にOFF（Shift+N）

## 修正後の確認事項

### 1. DRCチェック
```
メニュー → Inspect → Design Rules Checker → Run DRC
✓ Errors: 0
✓ D46のエラーが消えている
```

### 2. 3Dビューで確認
```
メニュー → View → 3D Viewer
✓ LEDがキースイッチと干渉していない
✓ 基板内に収まっている
```

### 3. 信号線の接続確認
- [ ] D46のVDD → VCC
- [ ] D46のVSS → GND
- [ ] D46のDIN → 前のLEDのDOUT
- [ ] D46のDOUT → 次のLEDのDIN

---

## まとめ

**最も簡単な解決策**:
1. D46を選択 → `M`キー
2. **下方向に1.0mm移動**
3. クリックで確定
4. 配線を再接続
5. DRC実行 → エラー0確認

**所要時間**: 5～10分

この修正により、D46の基板端クリアランス違反が解消されます。
