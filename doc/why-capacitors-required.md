# なぜコンデンサ・抵抗が必要か - LED有無に関わらず必須

## ❌ よくある誤解

> 「LEDなしにするから、コンデンサは不要だよね？」

**これは間違いです！**

## ✅ 正しい理解

### LED有無とコンデンサの関係

```
LED有り の場合:
├── 基本コンデンサ（必須）
│   ├── デカップリング 0.1μF × 4-5個  ← マイコン用（必須）
│   └── バイパス 10μF × 1-2個         ← マイコン用（必須）
└── LED用コンデンサ（追加）
    └── バイパス 10μF × 2個           ← LED電源安定化用

LED無し の場合:
└── 基本コンデンサ（必須）
    ├── デカップリング 0.1μF × 4-5個  ← マイコン用（必須）
    └── バイパス 10μF × 1-2個         ← マイコン用（必須）
```

**LEDをなしにしても、基本コンデンサは必須です！**

---

## 🔌 なぜコンデンサが必須なのか

### 1. デカップリングキャパシタ（0.1μF × 4-5個）

#### 役割: マイコンの電源ノイズ除去

```
VCC (3.3V) ─┬───────── nice!nano/GRAEATZT NFR52840
            │
            ├─ [C1: 0.1μF] ── GND
            ├─ [C2: 0.1μF] ── GND
            ├─ [C3: 0.1μF] ── GND
            └─ [C4: 0.1μF] ── GND

配置: マイコンの近く（5mm以内）
```

#### なぜ必要か

**マイコンの内部動作:**
- CPUクロック: 64MHz（nRF52840）
- GPIO切り替え: 数MHz～数十MHz
- 無線通信: 2.4GHz
- これらが**瞬間的に電流を消費**

**コンデンサがないと:**
```
❌ 電源電圧が不安定
   → VCC: 3.3V → 3.1V → 3.4V → 2.9V...（変動）
   
❌ 高周波ノイズが発生
   → デジタル信号が乱れる
   
❌ マイコンが誤動作
   → 突然リセット
   → キー入力が認識されない
   → Bluetooth接続が不安定
   → USB通信エラー
```

**コンデンサがあると:**
```
✅ 瞬間的な電流変動を吸収
✅ 電源電圧を3.3Vに安定維持
✅ 高周波ノイズを除去
✅ マイコンが安定動作
```

---

### 2. バイパスキャパシタ（10μF × 1-2個）

#### 役割: 電源電圧の急激な変動を抑制

```
VCC (3.3V) ─┬───────── nice!nano/GRAEATZT NFR52840
            │
            └─ [C_BYPASS: 10μF] ── GND

配置: マイコンの直近
```

#### なぜ必要か

**マイコンの動作モード変化:**
```
スリープモード: 数μA
  ↓ 突然の変化
通信モード: 数十mA～100mA以上
```

この**瞬間的な電流変化**が問題になります。

**バイパスキャパシタがないと:**
```
❌ スリープ→通信時に電圧降下
   VCC: 3.3V → 2.8V（瞬間的）
   
❌ マイコンが電圧不足でリセット
   → 突然再起動
   → Bluetooth切断
   → キー入力が消える
```

**バイパスキャパシタがあると:**
```
✅ コンデンサに貯めた電荷で瞬間的な電流をカバー
✅ 電源電圧の急激な降下を防ぐ
✅ マイコンが安定動作
```

---

### 3. プルアップ抵抗（10kΩ × 1個）

#### 役割: リセットピンを安定させる

```
VCC (3.3V)
  │
  └─ [R1: 10kΩ] ──┬── nice!nano Pin 22 (RST)
                   │
               [SW_RST]
                   │
                  GND
```

#### なぜ必要か

**RSTピンの特性:**
- Low (0V): リセット実行
- High (3.3V): 通常動作
- **未接続（フローティング）: 不定（危険！）**

**プルアップ抵抗がないと:**
```
❌ RSTピンがフローティング状態
   → ノイズで勝手にLowになる
   → 突然リセット
   → 常にリセット状態で起動しない
```

**プルアップ抵抗があると:**
```
✅ RSTピンを常にHighに保つ
✅ ボタンを押したときだけLowになる
✅ 正常にリセット機能が動作
```

## 🔍 実際の失敗例

```
状況: デカップリングキャパシタを省略

- Bluetooth接続が数秒で切れる

```

```

- 常にリセット状態
- ファームウェアを書き込めない
解決: 10kΩ抵抗を追加して正常動作
```

## ✅ まとめ

### LED有無に関係なく必須
1. **0.1μF コンデンサ × 4-5個** - マイコンのノイズ除去
2. **10μF コンデンサ × 1-2個** - 電源安定化
3. **10kΩ 抵抗 × 1個** - リセット回路

### これらがないと
- ❌ マイコンが誤動作・突然リセット
- ❌ Bluetooth/USB通信が不安定
- ❌ キー入力が認識されない
- ❌ リセットボタンが機能しない
- ❌ 最悪の場合、全く動作しない

### LEDをなしにして減る部品
- LED本体 × 42-50個
- LED用470Ω抵抗 × 1個
- LED用追加10μFコンデンサ × 2個

**基本のコンデンサ・抵抗は絶対に必要です！**
