# KiCad PCBエディタ - フットプリントを裏面に配置する方法

## 最も簡単な方法 ⭐

フットプリントを裏面（B.Cu）に配置する最も簡単な方法です。

### ステップ1: フットプリントを選択
- nice!nano/nrf52840のフットプリントをクリック
- フットプリント全体がハイライト表示される

### ステップ2: フリップ（裏返し）
- キーボードの **`F`** キーを押す
- または、右クリック → **`Flip`** を選択

### ステップ3: 完了
- フットプリントが裏面（B.Cu）に移動
- 色が変わる（紫/青色に）
- これだけで完了！

### ステップ4: 位置調整
- `M`キーで移動モード
- 中央スペースなど適切な位置に配置
- クリックで確定

---

## 詳細操作

### レイヤーの確認方法

#### 色で確認
- **赤色**: 表面 (F.Cu)
- **紫/青色**: 裏面 (B.Cu)

#### プロパティで確認
1. フットプリントを選択
2. `E` キーを押す
3. `Layer` を確認
   - `F.Cu` = 表面
   - `B.Cu` = 裏面

---

## フリップ後にやること

### 配線の修正

裏面に移動すると配線が切れるので、**ビア**で接続し直します。

#### ビアの追加方法
1. 配線ツール（`X` キー）
2. 表面のパッドから配線開始
3. 配線中に **`V`** キーを押す
4. ビアが配置され、裏面に切り替わる
5. マイコンのパッドまで配線
6. クリック

```
表面パッド → [ビア] → 裏面マイコン
```

---

## よくある操作

### キーボードショートカット

| キー | 動作 |
|------|------|
| **F** | フリップ（表⟷裏） |
| **M** | 移動 |
| **R** | 90度回転 |
| **E** | プロパティ |
| **X** | 配線ツール |
| **V** | ビア追加（配線中） |

### 複数のフットプリントを一括でフリップ
1. **Shift**を押しながら複数選択
2. `F`キーを押す
3. すべて裏面に移動

**例**: マイコン、バッテリーコネクタ、リセットボタンを一緒に裏面へ

## 3Dビューで確認

### 手順
1. メニュー → `View` → `3D Viewer`
2. または **`Alt + 3`**
3. マウスドラッグで回転
4. 裏側を確認

## トラブルシューティング

### Q: Fキーを押しても何も起こらない
**A**: フットプリント全体を選択してください
- 個別のパッドではなく、フットプリントの中央をクリック

### Q: 裏面に移動したら配線が全部切れた
**A**: 正常です
- ビアを使って表裏を接続し直してください

### Q: 裏面が見えない
**A**: レイヤーを確認
- 右側の`Layers`パネルで`B.Cu`にチェックが入っているか確認

### Q: 向きがおかしい
**A**: 回転してください
- `R`キー（90度回転）
- 必要に応じて複数回

## mami42での実装手順

### 推奨配置（Aliceレイアウト）

```
1. nice!nano/nrf52840 → 裏面中央
2. バッテリーコネクタ → 裏面
3. スイッチ用コネクタ → 裏面
4. リセットボタン → 裏面
```

### 実装手順
1. 各フットプリントを選択
2. `F`キーでフリップ
3. 中央スペースの裏側に配置
4. ビアで配線接続
5. DRCチェック
