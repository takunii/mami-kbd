# mami42 設計変更履歴

このドキュメントは、mami42キーボードの設計変更を時系列で記録します。

---

## 変更履歴

### 2026/5/1 - パワースイッチの実装方法変更

#### 変更内容
基板実装のON/OFFスイッチから、ケース側装着のスイッチへ変更

#### 変更前
- **実装方法**: 基板にSMDスライドスイッチを直接実装
- **部品**: MSK-12C02 (SMD スライドスイッチ)
- **フットプリント**: `Button_Switch_SMD:SW_SPDT_PCM12`
- **回路**: Battery+ → SW_PWR (基板上) → BATIN (Pin 24,34)

#### 変更後
- **実装方法**: ケース側にスイッチを装着、基板へは配線で接続
- **接続**: 基板にはスイッチ用のコネクタまたはパッドを配置
- **回路**: Battery+ → スイッチ用コネクタ/パッド → (ケース内配線) → ケース側スイッチ → (ケース内配線) → スイッチ用コネクタ/パッド → BATIN (Pin 24,34)

#### 変更理由
- ケース外部からのアクセス性向上
- スイッチ操作の利便性向上
- 基板レイアウトの柔軟性向上

#### 影響範囲
- **回路図**: SW_PWRシンボルを削除し、コネクタに変更
- **PCB設計**: SMDスイッチフットプリントを削除、コネクタパッドを追加
- **BOM**: MSK-12C02を削除、代わりにケース側スイッチとコネクタを追加
- **組立手順**: ケース側スイッチの取り付けと配線工程を追加

#### 必要な対応
- [ ] 回路図の更新（SW_PWRをコネクタに変更）
- [ ] PCBレイアウトの更新
- [ ] BOMの更新
- [ ] ケース設計の確認（スイッチ取り付け位置）
- [ ] 配線仕様の決定（ワイヤーゲージ、コネクタタイプ）
- [ ] 組立マニュアルの作成/更新

#### 推奨実装
**オプション1: スルーホールパッド**
```
基板:
  Battery+ → [TH PAD 1] ... (ケース内配線) ... [TH PAD 2] → BATIN

利点: はんだ付けが容易、配線が確実
欠点: 組立時にはんだ付け作業が必要
```

**オプション2: 2ピンコネクタ**
```
基板:
  Battery+ → [J_SW: Conn_01x02] 
  
コネクタピン配置:
  Pin 1: Battery+ から
  Pin 2: BATIN へ

利点: 着脱可能、組立が容易
欠点: コネクタの追加コスト、スペース確保が必要
推奨コネクタ: JST PH 2.0mm (B2B-PH-K)
```

**推奨**: オプション2（2ピンコネクタ）
- メンテナンス性が高い
- 組立/分解が容易
- バッテリーコネクタと同じJST PHシリーズで統一可能
