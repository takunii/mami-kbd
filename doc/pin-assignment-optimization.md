# mami42 ピンアサイン最適化

## ⚠️ 重要: PCB裏面実装の考慮

### 実装方向
- **nice!nanoはPCB裏面に実装**
- **USBコネクタは基板裏側（下向き）**
- **ピン配置が左右反転する**

### 反転の影響
```
表面から見た場合（部品面から）:
  回路図の左側ピン → 実際は右側
  回路図の右側ピン → 実際は左側
```

## 配線最適化の原則

### 基本方針（裏面実装を考慮）
- **上側ピン → COL（列・出力）**: マトリクスの列信号は上側に配置
- **下側ピン → ROW（行・入力）**: マトリクスの行信号は下側に配置
- **左右反転を考慮**: 回路図シンボルと実際の配置が鏡像関係
- **配線の交差を最小化**: 信号線が交差しないように配置

## 最適化されたピンアサイン

### ✅ 推奨案（配線が最もきれい）

#### 列ピン（COL）- 出力・上側優先
```
col0: Pin 1  (TX0/P0.06)    - 左側最上部 ✓
col1: Pin 2  (RX1/P0.08)    - 左側上部 ✓
col2: Pin 5  (P0.17)        - 左側上部 ✓
col3: Pin 6  (P0.20)        - 左側中央 ✓
col4: Pin 7  (P0.22)        - 左側中央 ✓
col5: Pin 8  (P0.24)        - 左側中央 ✓
```
**メリット**: 6本のCOLピンが左側の上～中央に連続して配置

#### 行ピン（ROW）- 入力・下側優先

**左側4行（下側に配置）**
```
row0: Pin 9  (P1.00)        - 左側下部 ✓
row1: Pin 10 (P0.11)        - 左側下部 ✓
row2: Pin 11 (P1.04)        - 左側下部 ✓
row3: Pin 12 (P1.06)        - 左側最下部 ✓
```

**右側4行（上側に配置）**
```
row4: Pin 13 (NFC1/P0.09)   - 右側最上部 ○
row5: Pin 14 (NFC2/P0.10)   - 右側上部 ○
row6: Pin 15 (P1.11)        - 右側上部 ○
row7: Pin 16 (P1.13)        - 右側上部 ○
```
**注意**: 右側のROWは上部にあるため、理想的ではありませんが、利用可能なピンの制約上これが最適

### 電源・その他
```
VCC:   Pin 21 (右側下部)
GND:   Pin 3,4,23,30
RST:   Pin 22 (右側下部)
BATIN: Pin 24,34 (右側下部)
```

## 配線イメージ

### 回路図上のイメージ
```
      nice!nano (シンボル)
   ┌───────────────┐
L  │ 1  COL0   13 │ R    ROW4 ← 回路図右側
E  │ 2  COL1   14 │ I    ROW5
F  │ 3  GND    15 │ G    ROW6
T  │ 4  GND    16 │ H    ROW7
   │ 5  COL2   17 │ T    (未使用)
   │ 6  COL3   18 │      (未使用)
   │ 7  COL4   19 │      (未使用)
   │ 8  COL5   20 │      (未使用)
   │ 9  ROW0   21 │      VCC
   │10  ROW1   22 │      RST
   │11  ROW2   23 │      GND
   │12  ROW3   24 │      BATIN
   └───────────────┘
       31 32 33
      (P1.01, P1.02, P1.07)
```

### PCB実装時の実際の配線（表面から見た場合）
```
   キーマトリクス左側           nice!nano裏面実装           キーマトリクス右側
                              (表面から見て)
   
   COL信号 ──────→  Pin 1-8 (実際は右側) 
                    ↑ 
                    COL0-5が上～中央に集中
                    配線が短くきれい
   
   ROW信号(左) ───→  Pin 9-12 (実際は右側下部)
                    ↑
                    左側マトリクスに近い
                    
                              Pin 13-16 (実際は左側上部) ←─── ROW信号(右)
                              ↑
                              右側マトリクスに近い
```

### 配線のポイント
1. **COLピン（1-8）は実際には右側に来る** → マトリクス全体にアクセスしやすい
2. **左ROW（9-12）は実際には右側下部** → マトリクス左側への配線が短い
3. **右ROW（13-16）は実際には左側上部** → マトリクス右側への配線が短い
4. **左右反転により、配線がより最適化される**

## 配線の流れ（裏面実装考慮）

### COL信号
```
回路図: Pin 1-8は左側
実装後: Pin 1-8は右側（表面から見て）
    ↓
マトリクス左右 → nice!nano Pin 1-8 (実際は右側上～中央)
         ↓
     中央から左右に配線、効率的
```

### ROW信号（左側マトリクス）
```
回路図: Pin 9-12は左側下部
実装後: Pin 9-12は右側下部（表面から見て）
    ↓
マトリクス左側4行 → nice!nano Pin 9-12 (実際は右側下部)
         ↓
     横断配線が必要だが、下部なので交差少ない
```

### ROW信号（右側マトリクス）
```
回路図: Pin 13-16は右側上部
実装後: Pin 13-16は左側上部（表面から見て）
    ↓
マトリクス右側4行 → nice!nano Pin 13-16 (実際は左側上部)
         ↓
     横断配線が必要だが、上部なので交差少ない
```

### ✅ 裏面実装の利点
1. **配線が分散**: COL信号が中央、ROW信号が左右に分散
2. **交差最小化**: 上下で信号が分離されるため交差が少ない
3. **対称的な配線**: 左右のROWが対称的に配置される

## 代替案の検討

### 案2: 右側ROWを下側に配置
```
row4-7: Pin 17,18,19,20 を使用？
```
**問題**: Pin 17-20は他の機能（P1.15, AIN0, AIN5, AIN7）で、
NFCピン（13,14）より優先度が低い。また、20までを使うと電源ピンに近すぎる。

### 案3: 下部ピン（31,32）を使用
```
row6: Pin 31 (P1.01)
row7: Pin 32 (P1.02)
```
**問題**: 下部ピンは基板上の配置が特殊で、配線が複雑になる可能性。

## PCB設計時の配線のコツ

1. **COL信号**: nice!nanoの左側からマトリクスの左右両側へ
2. **ROW信号（左）**: nice!nanoの左下からマトリクスの左側へ
3. **ROW信号（右）**: nice!nanoの右上からマトリクスの右側へ
4. **レイヤー分離**: 必要に応じてTop層とBottom層で信号を分離
5. **GNDプレーン**: 表裏両面にGNDプレーンを配置して配線を簡素化

## ZMKファームウェア設定

このピンアサインをZMKの設定ファイルに反映してください：

```dts
/ {
    chosen {
        zmk,kscan = &kscan0;
    };

    kscan0: kscan {
        compatible = "zmk,kscan-gpio-matrix";
        label = "KSCAN";

        diode-direction = "col2row";
        
        row-gpios
            = <&gpio1 0 (GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN)>   // P1.00 - row0
            , <&gpio0 11 (GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN)>  // P0.11 - row1
            , <&gpio1 4 (GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN)>   // P1.04 - row2
            , <&gpio1 6 (GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN)>   // P1.06 - row3
            , <&gpio0 9 (GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN)>   // P0.09 - row4
            , <&gpio0 10 (GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN)>  // P0.10 - row5
            , <&gpio1 11 (GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN)>  // P1.11 - row6
            , <&gpio1 13 (GPIO_ACTIVE_HIGH | GPIO_PULL_DOWN)>  // P1.13 - row7
            ;

        col-gpios
            = <&gpio0 6 GPIO_ACTIVE_HIGH>   // P0.06 - col0
            , <&gpio0 8 GPIO_ACTIVE_HIGH>   // P0.08 - col1
            , <&gpio0 17 GPIO_ACTIVE_HIGH>  // P0.17 - col2
            , <&gpio0 20 GPIO_ACTIVE_HIGH>  // P0.20 - col3
            , <&gpio0 22 GPIO_ACTIVE_HIGH>  // P0.22 - col4
            , <&gpio0 24 GPIO_ACTIVE_HIGH>  // P0.24 - col5
            ;
    };
};
```
