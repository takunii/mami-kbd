# mami42 周辺回路設計

## 📋 必要な回路一覧

### 必須回路
1. **電源回路** - VCC/GND接続、デカップリングキャパシタ
2. **マトリクス回路** - 42個のスイッチ+ダイオード（既存）

### 無線動作に必要
3. **バッテリー回路** - Li-Po充電・接続回路

### 推奨回路
4. **リセット回路** - ファームウェア書き込み・デバッグ用
5. **電源スイッチ** - バッテリー動作のON/OFF

### オプション回路
6. **ESD保護回路** - USB静電気保護
7. **LED回路** - 動作確認用LED

## 1. 電源回路 ⭐必須⭐

### 1-1. VCC/GND接続

#### 回路図
```
nice!nano
┌──────────┐
│ Pin 21   │──── VCC (3.3V) ────┬──── デカップリングキャパシタ群
│          │                    │
│ Pin 3    │──┐                 │
│ Pin 4    │──┤                 │
│ Pin 23   │──┼── GND ──────────┴──── GND
│ Pin 30   │──┘
└──────────┘
```

#### 必要な部品
| 部品 | 型番 | 数量 | 配置場所 | 備考 |
|------|------|------|----------|------|
| デカップリングキャパシタ | 0.1μF (0603) | 4個 | nice!nano近く | VCC-GND間 |
| バイパスキャパシタ | 10μF (0805) | 1個 | nice!nano近く | 電源安定化 |

#### KiCad実装手順
1. **VCC電源シンボル配置**
   - シンボル: `power:VCC`
   - nice!nano Pin 21に接続

2. **GND電源シンボル配置**
   - シンボル: `power:GND`
   - nice!nano Pin 3, 4, 23, 30にすべて接続

3. **デカップリングキャパシタ配置**
   ```
   C1: 0.1μF - VCC to GND (nice!nano左上付近)
   C2: 0.1μF - VCC to GND (nice!nano右上付近)
   C3: 0.1μF - VCC to GND (nice!nano左下付近)
   C4: 0.1μF - VCC to GND (nice!nano右下付近)
   C5: 10μF  - VCC to GND (nice!nano直近)
   ```

#### PCB設計時の注意
- デカップリングキャパシタはnice!nanoの**5mm以内**に配置
- VCCとGND間の距離を最短に
- GNDプレーンを表裏両面に配置

## 2. バッテリー回路 ⭐無線動作必須⭐

### 2-1. バッテリー接続回路

> **⚠️ 設計変更 (2026/5/1)**  
> パワースイッチは基板実装からケース側装着へ変更されました。  
> 詳細は [design-changes.md](./design-changes.md) を参照してください。

#### 回路図
```
Li-Po Battery (3.7V)
    (+)
     │
     ├── [J_SW: Switch Connector] ─── (ケース内配線) ─── [ケース側スイッチ] ─── (ケース内配線) ─── [J_SW: Pin 2]
     │                                                                                                    │
     │                                                                                ┬── nice!nano Pin 24 (BATIN)
     │                                                                                └── nice!nano Pin 34 (BATIN)
     │
    (-)
     │
     └──────────────────────────────────────────────────────────────────────────────── GND
```

#### 必要な部品
| 部品 | 型番 | 数量 | 備考 |
|------|------|------|------|
| Li-Poバッテリー | 301230 (3.7V 110mAh) | 1 | または同等品 |
| バッテリーコネクタ | JST PH 2.0mm (B2B-PH-K) | 1 | 2ピン |
| スイッチ用コネクタ | JST PH 2.0mm (B2B-PH-K) | 1 | 2ピン、ケース側スイッチ接続用 |
| パワースイッチ | 各自選択 (ケース側) | 1 | ケースに装着、SPST推奨 |
| 配線 | AWG26～28 | 適量 | ケース内スイッチ配線用 |
| 保護ダイオード | 1N4148W (SOD-123) | 1 | 逆接続保護（オプション） |

#### 詳細回路（保護ダイオード付き）
```
Battery (+) ──┬── [D_BATT: 1N4148W] ──┬── [J_SW: Pin 1] ─── (ケース配線) ─── [ケース側スイッチ] 
              │      カソード側        │                                              │
              │                        │                                              │
              └── (未接続時は開放)    └── スイッチ用コネクタ        (ケース配線) ───┘
                                                                                       │
                                                            [J_SW: Pin 2] ── BATIN (Pin 24,34)
              
Battery (-) ───────────────────────────────────────────────────────────────────────── GND
```

**ケース側スイッチの配線例**
```
基板 [J_SW Pin 1] ←─── (配線) ←─── [スイッチ 端子1]
                                          │
                                     (スイッチ動作)
                                          │
基板 [J_SW Pin 2] ─→── (配線) ─→─── [スイッチ 端子2]
```

#### KiCad実装手順
1. **バッテリーコネクタ配置**
   - シンボル: `Connector:Conn_01x02_Pin`
   - リファレンス: J_BATT
   - フットプリント: `Connector_JST:JST_PH_B2B-PH-K_1x02_P2.00mm_Vertical`
   - Pin 1: Battery+
   - Pin 2: Battery- (GNDに接続)

2. **スイッチ用コネクタ配置** ⭐変更点⭐
   - シンボル: `Connector:Conn_01x02_Pin`
   - リファレンス: J_SW
   - フットプリント: `Connector_JST:JST_PH_B2B-PH-K_1x02_P2.00mm_Vertical`
   - Pin 1: Battery+から（スイッチ入力側）
   - Pin 2: BATINへ（スイッチ出力側）
   - **注意**: ケース側のスイッチと配線で接続

3. **保護ダイオード配置（推奨）**
   - シンボル: `Diode:1N4148W`
   - リファレンス: D_BATT
   - Battery+とスイッチコネクタ間に配置
   - **カソード**をスイッチコネクタ側に（順方向）

4. **BATIN接続**
   - nice!nano Pin 24とPin 34を並列接続
   - スイッチコネクタPin 2に接続

5. **ケース側の実装**（基板外）
   - パワースイッチをケースに装着
   - 配線（AWG26～28推奨）でJ_SWと接続
   - 極性に注意（Pin 1: 入力、Pin 2: 出力）

## 3. リセット回路 ⭐推奨⭐

### 3-1. リセットボタン回路

#### 回路図
```
VCC (3.3V)
  │
  ├── [R1: 10kΩ] ─┬── nice!nano Pin 22 (RST)
  │               │
                  │
              [SW_RST]
                  │
                  └── GND
```

#### 必要な部品
| 部品 | 型番 | 数量 | 備考 |
|------|------|------|------|
| プルアップ抵抗 | 10kΩ (0603) | 1 | RST-VCC間 |
| タクトスイッチ | SKQGABE010 | 1 | 表面実装型 |

#### KiCad実装手順
1. **プルアップ抵抗配置**
   - シンボル: `Device:R`
   - リファレンス: R1
   - 値: 10kΩ
   - VCCとRSTピン間に接続

2. **リセットスイッチ配置**
   - シンボル: `Switch:SW_Push`
   - リファレンス: SW_RST
   - フットプリント: `Button_Switch_SMD:SW_SPST_B3U-1000P`
   - RSTピンとGND間に接続

#### 動作原理
- 通常: R1によりRSTがVCCにプルアップ（High）→ 動作中
- ボタン押下: RSTがGNDに接続（Low）→ リセット
- ボタン開放: 自動的にHighに戻る → 再起動

## 4. ESD保護回路（オプション）

### 4-1. USB ESD保護

#### 回路図
```
USB D+ ──┬── [TVS Diode] ── GND
         │
USB D- ──┴── [TVS Diode] ── GND
```

#### 必要な部品
| 部品 | 型番 | 数量 | 備考 |
|------|------|------|------|
| ESD保護IC | USBLC6-2SC6 (SOT23-6) | 1 | USB専用ESD保護 |

#### 注意
- nice!nanoには既にESD保護が内蔵されている可能性が高い
- 追加保護が必要な場合のみ実装
- 通常は**不要**

## 5. 動作確認用LED回路（オプション）

### 5-1. ステータスLED

#### 回路図
```
nice!nano Pin 17 (P1.15)
  │
  ├── [R2: 1kΩ] ─┬── [LED: アノード]
                  │
                [カソード]
                  │
                  └── GND
```

#### 必要な部品
| 部品 | 型番 | 数量 | 備考 |
|------|------|------|------|
| LED | 0603 (赤/青/緑) | 1 | 3.3V対応 |
| 電流制限抵抗 | 1kΩ (0603) | 1 | LED保護 |

#### KiCad実装手順
1. **LED配置**
   - シンボル: `Device:LED`
   - リファレンス: D_LED1
   - フットプリント: `LED_SMD:LED_0603_1608Metric`

2. **電流制限抵抗配置**
   - シンボル: `Device:R`
   - リファレンス: R2
   - 値: 1kΩ
   - GPIOピンとLEDアノード間に接続

3. **接続**
   - nice!nano Pin 17 → R2 → LED Anode → LED Cathode → GND

#### 使用可能なピン
- Pin 17 (P1.15): 未使用
- Pin 18 (P0.02): 未使用
- Pin 19 (P0.29): 未使用
- Pin 20 (P0.31): 未使用

## 🎯 PCB設計時の配置ガイド

### レイアウト優先順位
1. **nice!nano**: 中央に配置
2. **デカップリングキャパシタ**: nice!nanoの四隅5mm以内
3. **バイパスキャパシタ**: nice!nano直下（裏面可）
4. **バッテリーコネクタ**: 基板端（ユーザーアクセス容易）
5. **パワースイッチ**: 基板端（操作しやすい位置）
6. **リセットボタン**: 基板端または裏面（アクセス可能位置）
7. **キーマトリクス**: レイアウトに従って配置

### 配線優先順位
1. **GNDプレーン**: 表裏両面に最優先配置
2. **VCC配線**: 太く短く（0.5mm以上）
3. **BATIN配線**: 太く（0.5mm以上）
4. **COL/ROW信号**: 標準幅（0.3mm以上）
